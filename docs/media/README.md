# Media

Pictures the README and the docs show. Every clone carries every picture ever committed, so `scripts/check_media_sizes.py`
keeps them small: a GIF at most 3 MB, a still image at most 400 KB, the folder at most 25 MB. Videos are attached to a
GitHub Release instead.

Captured from real runs, never mocked up:

| File | Shows |
|---|---|
| `hero.gif` | An agent's cursor tapping through an app in the viewer |
| `viewer.png` | The viewer in a browser tab |
| `cursor.gif` | The agent cursor leading a tap |
| `snapshot-vs-screenshot.png` | A snapshot beside a screenshot of the same screen |
| `iframe.png` | The viewer framed in another page |
| `doctor.png` | `sim-mirror doctor` on a Mac |
| `view-only.png` | The view-only mirror without idb_companion |
| `social-preview.png` | GitHub's social preview, 1280×640 |
